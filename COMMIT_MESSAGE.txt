feat: implement 4-factor feed relevance algorithm

Implements Section 5.1 from project report - Open Feed relevance algorithm with 4 factors:

1. Location Proximity (25% weight)
   - GPS location tracking with expo-location
   - Haversine distance calculation
   - Geocoding for circle locations
   - Proximity scoring (10km = 1.0, 100km+ = 0)

2. Travel Context (15% weight)
   - Track transit searches (route + date)
   - Store in user preferences
   - Boost matching circles (7-day window)
   - Exact match scoring

3. Join Velocity (20% weight)
   - Track join timestamps for each member
   - Calculate joins in last 24 hours
   - Boost trending circles (10+ joins = 1.0)
   - Cloud Function template for server-side calculation

4. Category Affinity (20% weight)
   - Track every circle join with category
   - Build user preference profile
   - Increment category affinity scores
   - Personalized recommendations

Additional Features:
- Composite relevance scoring with configurable weights
- Recency decay (20% weight)
- Client-side sorting with manual filter override
- User preferences Firestore collection
- Comprehensive documentation
